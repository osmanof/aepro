# AEPro

Веб-система для организации и проведения олимпиад и конкурсов.

AEPro покрывает основные этапы проведения мероприятия: регистрацию участников, настройку площадок и аудиторий, формирование вариантов заданий, распределение участников, проверку работ, обработку апелляций и публикацию результатов.

## Идея

Основная сущность системы — конкурс, внутри которого задаются уровни, задания, площадки и участники.

```text
Конкурс
   │
   ├── Уровни
   │    ├── Задания
   │    └── Варианты работ
   │
   ├── Площадки
   │    └── Аудитории
   │         └── Участники
   │
   ├── Эксперты
   │    └── Проверка работ
   │
   ├── Апелляции
   │
   └── Результаты и рейтинг
```

Система рассчитана не только на хранение результатов, но и на сопровождение самого процесса проведения конкурса.

## Основной процесс

```text
Создание конкурса
       │
       ▼
Настройка уровней и заданий
       │
       ▼
Создание площадок и аудиторий
       │
       ▼
Регистрация участников
       │
       ▼
Формирование вариантов работ
       │
       ▼
Проведение конкурса
       │
       ▼
Проверка экспертами
       │
       ▼
Апелляции
       │
       ▼
Публикация результатов
```

Для разных этапов конкурса предусмотрены отдельные состояния: начало и завершение регистрации, генерация работ, проверка, прием апелляций и публикация результатов.

## Возможности

* создание и настройка конкурсов;
* регистрация участников;
* работа с городами и образовательными организациями;
* разделение участников по уровням;
* создание площадок и аудиторий;
* распределение участников по местам;
* создание заданий и прототипов;
* автоматическое формирование вариантов;
* генерация файлов конкурсных работ;
* назначение экспертов;
* проверка и выставление баллов;
* обработка апелляций;
* формирование рейтинга;
* экспорт результатов в XLSX;
* генерация протоколов и других документов в PDF.

## Архитектура

Проект построен как классическое серверное приложение на Laravel:

```text
Browser
   │
   │ HTTP
   ▼
Laravel Routes
   │
   ▼
Controllers
   │
   ├── Contest
   ├── Expert
   ├── Authentication
   └── File generation
   │
   ▼
Eloquent Models
   │
   ▼
Database
```

Интерфейс формируется на сервере через Blade-шаблоны. JavaScript и frontend-ресурсы собираются через Vite.

Генерация документов вынесена в отдельную часть приложения. Для PDF используется `dompdf`, для таблиц — `PhpSpreadsheet`. Часть конкурсных работ формируется из LaTeX-шаблонов с последующей компиляцией в PDF.

## Основные сущности

**Contest** — конкурс и его текущее состояние.

**ContestMember** — участник конкретного конкурса.

**Level** — уровень или категория участников.

**Task** — задание конкурса.

**TaskPrototype** — конкретный вариант задания, используемый при формировании работы.

**ContestOption** — сформированный вариант конкурсной работы.

**Place** — площадка проведения.

**Auditorium** — аудитория внутри площадки.

**Expert** — эксперт, выполняющий проверку работ.

## Запуск

```bash
git clone https://github.com/osmanof/aepro.git
cd aepro

composer install
npm install
```

Создать конфигурацию окружения:

```bash
cp .env.example .env
php artisan key:generate
```

Подготовить базу данных:

```bash
php artisan migrate
```

Запустить frontend-сборщик:

```bash
npm run dev
```

И Laravel:

```bash
php artisan serve
```
